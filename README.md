# آینه‌جان

پرو مجازی رژ لب، لنز رنگی، لاک ناخن و لباس — همه‌چیز روی خودِ گوشی.

تصویر دوربین از دستگاه بیرون نمی‌رود. هیچ بک‌اندی وجود ندارد و هیچ درخواستی
به CDN یا سرویس بیرونی زده نمی‌شود؛ مدل‌ها، فونت و همهٔ فایل‌ها داخل خود اپ‌اند.

## نصب و اجرا

نیاز: Node.js نسخهٔ ۲۰ یا بالاتر.

```bash
npm install          # وابستگی‌ها + دریافت خودکار مدل‌ها (postinstall)
npm run dev          # اجرا روی شبکهٔ محلی با HTTPS
```

اگر دریافت مدل‌ها نیمه‌کاره ماند، دستی اجرا کن:

```bash
npm run setup
```

این دستور فایل‌های WASM را از `node_modules` کپی می‌کند و چهار مدل را در
`public/mediapipe/models` می‌گذارد. فقط همین یک مرحله به اینترنت نیاز دارد؛
بعد از آن اپ کاملاً آفلاین کار می‌کند.

### باز کردن روی گوشی

۱. گوشی و کامپیوتر باید روی یک شبکهٔ وای‌فای باشند.
۲. بعد از `npm run dev` نشانی جلوی **Network** را بردار، چیزی شبیه
   `https://192.168.1.20:5173`.
۳. همان را در مرورگر گوشی باز کن.
۴. مرورگر دربارهٔ گواهی هشدار می‌دهد چون گواهی خودامضاست. روی
   «Advanced» یا «پیشرفته» بزن و ادامه بده. این فقط برای حالت توسعه است.
۵. اجازهٔ دوربین را بده.

دسترسی به دوربین جز روی `localhost` فقط روی نشانی امن (https) ممکن است؛ به
همین دلیل سرور توسعه هم روی https بالا می‌آید.

### ساخت نسخهٔ نهایی

```bash
npm run build        # خروجی در dist/
npm run preview      # پیش‌نمایش همان خروجی
```

## انتشار روی سرور

راهنمای کامل در [`DEPLOY.md`](./DEPLOY.md). خلاصه:


## ساختار

```
src/
  composables/     useCamera (دوربین) و useTryOnLoop (حلقهٔ رندر)
  renderers/       یک رندرر برای هر دسته: lip / lens / nail / garment
  lib/             لندمارک‌ها، فیلتر One Euro، هندسه، بارگذاری مدل، ذخیرهٔ عکس
  data/items.js    همهٔ آیتم‌ها، آمادهٔ جایگزینی با یک API
  views/           خانه، انتخاب آیتم، پرو
public/mediapipe/  فایل‌های WASM و مدل‌ها (محلی)
```

هر رندرر سه کار بلد است: `init()`، `detect(video, ts)` و
`draw(ctx, result, item, frame)` — به‌علاوهٔ `drawDebug()` برای لایهٔ اشکال‌زدایی.

### لایهٔ اشکال‌زدایی

در صفحهٔ پرو، نام دسته در نوار بالا را حدود یک ثانیه نگه دار. لندمارک‌های خام،
شمارهٔ هر نقطه و نرخ فریم روی تصویر کشیده می‌شوند. یک‌بار دیگر نگه‌داشتن،
خاموشش می‌کند. برای تنظیم دقیق محل قرارگیری از همین استفاده کن.

## سرعت بالا آمدن

- موتور WASM مشترک است و به‌محض باز شدن اپ در پس‌زمینه گرم می‌شود.
- مدلِ هر دسته از همان صفحهٔ انتخاب رنگ پیش‌دریافت می‌شود، پس وقتی کاربر روی
  یک رنگ می‌زند معمولاً چیزی برای انتظار نمانده.
- فایل مدل در Cache Storage می‌ماند؛ دفعات بعد صفر ثانیه.
- هنگام دانلود، درصد واقعی نشان داده می‌شود، نه چرخ‌فلک بی‌پایان.

## محدودیت‌های هر بخش

### رژ لب
- کانتور بیرونی لب پر می‌شود و کانتور داخلی از آن کم می‌شود، پس دندان و داخل
  دهان هیچ‌وقت رنگی نمی‌شوند.
- لبه کمی محو می‌شود و رنگ با حالت `multiply` روی بافت طبیعی لب می‌نشیند، نه
  به‌صورت یک لکهٔ تخت.
- در چرخش‌های خیلی زیاد سر (بیش از حدود ۴۵ درجه) دقت افت می‌کند.
- در نور خیلی کم، رنگ‌های روشن کم‌جان دیده می‌شوند؛ این همان رفتار واقعی رژ
  روشن در نور کم است، ولی ردیابی هم سخت‌تر می‌شود.

### لنز
- مرکز و شعاع عنبیه از چهار نقطهٔ حلقهٔ عنبیهٔ مدل حساب می‌شود.
- لنز به کانتور پلک بریده می‌شود، پس روی پلک نمی‌افتد و هنگام پلک زدن جمع
  می‌شود و محو می‌گردد.
- مردمک شفاف می‌ماند و برقِ چشم از تصویر واقعی برگردانده می‌شود.
- روی چشم‌های خیلی تیره، لنزهای روشن کمی مصنوعی‌تر دیده می‌شوند — مثل خودِ
  لنز واقعی روی عنبیهٔ تیره.
- اگر فرد عینک داشته باشد، انعکاس شیشه دقت را کم می‌کند.

### ناخن
- **این مهم است:** مدلِ دست، خودِ صفحهٔ ناخن را تشخیص نمی‌دهد. فقط بیست‌ویک
  مفصل دست را می‌دهد. جای ناخن از روی جهت مفصل انتهایی تا نوک انگشت و پهنای
  دست تخمین زده می‌شود. یعنی نتیجه یک تقریب حساب‌شده است، نه اندازه‌گیری.
- ناخن فقط وقتی کشیده می‌شود که پشت دست رو به دوربین باشد.
- ناخن‌های خیلی بلند یا خیلی کوتاه با تخمین پیش‌فرض کمی فرق دارند.
- انگشتی که مستقیم به سمت دوربین گرفته شود، کوتاه دیده می‌شود و تخمین هم
  همان‌قدر کوتاه می‌شود؛ ولی در زاویه‌های خیلی تند دقت افت می‌کند.

### لباس
- **این یک پوشش دوبعدی است، نه شبیه‌سازی پارچه.** تصویر لباس با تبدیل
  چهارنقطه‌ای روی چهارضلعیِ شانه و لگن می‌نشیند و با پهنای شانه، طول تنه و کجی
  بدن تطبیق پیدا می‌کند. چین‌وچروک و افتادن پارچه شبیه‌سازی نمی‌شود.
- شانه و لگن هر دو باید داخل کادر باشند؛ وگرنه اپ می‌گوید کمی عقب‌تر برو.
- سر و گردن با ماسک قطعه‌بندی جلوی لباس می‌آیند؛ ساعدها هم تا جایی که
  تشخیص داده شوند.
- اگر دست‌ها بالا باشند یا بدن خیلی بچرخد، آستین‌ها سرِ جای درست نمی‌مانند.

## ذخیرهٔ عکس

مرورگر اجازه ندارد مستقیم در گالری بنویسد. اگر مرورگر «هم‌رسانی فایل» را
پشتیبانی کند، عکس به برگهٔ اشتراک‌گذاری سیستم داده می‌شود: در آیفون «Save
Image» و در اندروید انتخاب مقصد. در غیر این صورت فایل با نام زمان‌دار دانلود
می‌شود که در اندروید از گالری هم دیده می‌شود.

عکس ذخیره‌شده دقیقاً همان بومی است که روی صفحه بوده — با همان آینه‌شدن دوربین
سلفی و همان کادر.
